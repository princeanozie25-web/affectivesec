# Pre-registrations

Put one file here for each experiment, before the experiment runs. Each file states:

1. The hypothesis.
2. The falsifier: the result that makes the hypothesis false.
3. The metrics, the thresholds and the sample sizes (seeds, tasks).
4. The number of variants that you will test. The analysis corrects for this number.

Commit the file first. Then run the experiment. Cite the commit hash in the results.
If you change the file after you see data, record the change as a new hypothesis with a link to the old one.
